# 数学与理科知识点

这是 `gen-knowledge-video` 的一个领域包。重点补充公式、推导、单位和演算的画法。

## 1. 槽位调整

| 通用槽位 | 理科内容 |
| --- | --- |
| `hook` | 一个反直觉结果、估算错误或现实现象 |
| `define` | 定义 + 公式 + 适用条件 |
| `how` | 推导或机制；可拆成 `derive` + `how` |
| `example` | 代入一组数字，完整算一遍 |
| `boundary` | 定义域、单位、极限情况、近似条件 |
| `apply` | 什么时候用、怎么选公式 |
| `recap` | 条件、公式、步骤、易错点 |

可选模块：`derive`、`compare`、`misconception`、`practice`、`history`。

## 2. 公式念法

| 符号 | 旁白 |
| --- | --- |
| `A = P(1+r)^n` | `A 等于 P 乘以 1 加 r 的 n 次方` |
| `a² + b² = c²` | `a 的平方加 b 的平方等于 c 的平方` |
| `(x+1)/(x-1)` | `x 加 1 除以 x 减 1` |
| `Δx → 0` | `德尔塔 x 趋近于 0` |
| `∫ f(x) dx` | `f x 对 x 的积分` |
| `H₂SO₄` | `硫酸`（画面标注化学式） |
| `10⁻³ mol/L` | `十的负三次方摩尔每升` |

原则：**旁白念人话，画面保留符号**。不要把 LaTeX 源码直接念出来。

## 3. 推导画面

- 公式先完整出现，再逐项高亮。
- 每一步推导单独一帧/一段，不要跳步。
- 代入数字时，符号替换过程要可见：`A = P(1+r)^n` → `A = 10(1+0.07)^30` → `A ≈ 76.1`。
- 单位和量纲单独标注。
- 近似要说明条件：`当 x 很小时，sin x ≈ x`。

## 4. 图表

- 坐标轴、单位、刻度必须完整；不要用装饰性曲线。
- 关键点（交点、极值、阈值）用旁白同一时刻高亮。
- 变化趋势用位置/长度表达，不要只靠颜色。
- 示意图和真实比例冲突时，明确写“示意图，非按比例”。

## 5. 演算段

- 数字要具体，单位要一致。
- 先手算一遍，确认旁白、画面、结果三者一致。
- 中间量至少展示一次，不要从题目直接跳到答案。
- 结果保留有效数字时说明规则。

## 6. 常见坑

- 公式和解释同时出现，观众不知道看哪。
- 只给答案不给过程。
- 单位漏写或前后不一致。
- 近似条件没讲，例子在边界外。
- 用动画旋转三维图形代替关键截面。
