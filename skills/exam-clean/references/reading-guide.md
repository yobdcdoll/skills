# 读图指南：把照片里的印刷内容读准确

目标：只提取**印刷体**的题干与图形，丢掉一切**铅笔手写**的作答，然后准确转成文字/结构。
读不准，后面排得再漂亮也没用 —— 这一步是整条链路里最容易出错、也最值得花时间的地方。

## 一、放大裁剪的基本功

不要整页一次看全。**按区域裁剪 → 放大 → 增强 → 用视觉模型读**。

```bash
# 大块定位（横扫一段，2~3x）：
convert R_full.jpg -crop 842x400+0+1560 +repage -resize 250% -normalize /tmp/blk.jpg

# 小块精读（一行/一个数字，4~6x + sharp）：
convert R_full.jpg -crop 300x46+320+2072 +repage -resize 500% -normalize -sharpen 0x1 /tmp/zoom.jpg
```

参数说明：
- `-crop WxH+X+Y`：`+X+Y` 是左上角坐标（相对原图）。
- `-resize 500%`：放大到 5 倍；文字越小放大越多。
- `-normalize`：拉伸对比度，让淡墨变清晰。
- `-sharpen 0x1`：锐化，帮助分辨相邻笔画。
- 灰度化（源是彩色时加 `-colorspace Gray`）能减少干扰。

**先粗扫列大纲，再逐块精读。** 粗扫时记下「每个大题的起始 y 坐标」，避免漏题。

## 二、区分印刷体 vs 手写体

| 特征 | 印刷体 | 铅笔手写 |
|---|---|---|
| 笔画 | 均匀、规整、有衬线/标准字形 | 有轻重、抖动、粗细不均 |
| 位置 | 在格子/横线/括号里规规矩矩 | 常常超出横线、压到别的字上 |
| 边缘 | 干净锐利 | 毛糙、有涂抹/擦痕 |
| 颜色 | 偏黑（本例正文≈99，标题≈31） | 偏灰但**核心可能更深**（≈89） |

关键判断：**凡是在「( )」「___」「○」「□」里的、或竖式答案位置上的数字，都是作答，不是题干。** 题干本身一般不含答案数字。

> 注意：铅笔核心灰度可能**比印刷正文更深**，所以不要用「谁深谁是印刷体」来区分 —— 只能靠**字形规整度**和**位置**判断。

## 三、必须逐块精读的「高危区」

这几类最容易读错，务必单独放大 4~6x 核对：

1. **数字**：`24` vs `56`、`40` vs `34`、`7` vs `1`、`6` vs `8` 极易混。**逐位截取**，或左右各挪几像素多裁几张交叉比对。
2. **运算符**：`＋` vs `−`，尤其竖式里手写压痕会改形。
3. **题号/编号**：`(1)(2)(3)`、`一、二、三` 容易漏，漏一个可能就漏一整块。
4. **单位**：本/棵/朵/人/岁/元，常小字，漏了题意就变。
5. **被铅笔压住的印刷数字**：多裁几个位偏，取「笔画最规整」的那个解释；**仍不确定就在交付里标注请用户确认**，别蒙。

## 四、图形题的读法（重排时要连形状一起还原）

### 开火车（数列运算链）
一排车厢，车厢间是 `＋N→` / `−N→`。要点：
- **看清火车头在哪端**。有的卷子第二列火车头在**右端**（数字从右往左推），方向读反整列就错。
- 每节车厢是一个数，箭头上是运算。已知起点就顺推，只给终点就逆推（逆运算）。
- 重排时用 `.train / .tbox / .arrow / .loco` 样式，保持「车厢—箭头」交替。

### 图形式子（水果/图形竖式）
用图形代表数字的竖式，如 `🍎5 − 🍑🍎 = 7`。要点：
- **图形与数字的相对位置**要读准（哪个是十位、哪个是个位）。
- 同一图形在不同算式里是同一个数字；不同图形是不同数字。可用**列竖式凑数**验证读得对不对（十位、个位对齐）。
- 图形用 emoji 或 SVG 占位，保持竖式对齐。

### 线段图（条形比较图）
两根横条代表两个量，注有数量与「差」。要点：
- 读清**哪条长、哪条短、标注的数量**，以及差值标注在谁身上。
- 「? 棵 / ? 朵」表示要求的量。
- 重排用 `.bars / .barrow / .bar / .barlabel / .barnote`。

### 表格
行列标题 + 数据。逐格读，`37本 / 38本 / …` 别串行。重排用 `table.db`。

## 五、读完一定要「过一遍」

- 按题号顺序**通读**你整理出的清单，检查：有没有跳号？大题之间有没有漏掉一整块（如「三、」读完还有没有「四、」）？
- **跨页**的卷子，左右页各自过一遍，别只顾左页漏右页。
- **数字自洽检查**：题干里的数字和已知条件应能推出合理答案；若和用户的手写答案/草稿差很多，很可能你读错了题干数字（也可能题目本身就有点小毛病）——无论如何，**以印刷体为准**并把存疑点告诉用户。

## 六、把结果整理成结构化清单

读完交给下一步（重排）的，应该是类似这样的东西：

```
【左页】
一、基础小天地
 1. 直接写出得数（12题）: 35-6 7+73 84-6 57-13 / 52+30 ... （四列三行）
 2. 列竖式: 74-36  80-34  63+37
 3. 找规律: (1) 92 85 78 ( )( )( )   (2) 38 44 50 ( )( )( )
 4. 开火车: 列车1 [72]+27→ ... ；列车2 车头在右 [88] 逆推
二、数学与生活
 1. 线段图: 梨树43 / 苹果树少18 → ?棵 ；玫瑰花32 / 杜鹃花少12 → ?朵
 ...
```

有了这份清单，再用 `references/template.html` 重排就很快了。
